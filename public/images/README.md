# 📸 Изображения MyVault

В этой папке хранятся кинематографические изображения приложения.

## Файлы

- `splash-bg.png` — фон для заставки (кинематографический череп в тумане)
- `splash-skull.png` — главный череп для заставки (крупный план)
- `app-bg.png` — фон для приложения (атмосферный)
- `icon-audio.png` — иконка категории "Аудио" (череп в наушниках)
- `icon-photo.png` — иконка категории "Фото" (череп с камерой)
- `icon-code.png` — иконка категории "Код" (хакер-череп)
- `icon-idea.png` — иконка категории "Идеи" (череп с лампочкой)
- `icon-design.png` — иконка категории "Дизайн" (череп с кистью)

## Как добавить свои изображения

Просто положите PNG-файлы в эту папку с указанными именами.
Если изображения отсутствуют, приложение использует градиенты и SVG-иконки.
