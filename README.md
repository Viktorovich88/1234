# 🗄️ Моё Хранилище (MyVault)

Интеллектуальное личное хранилище всех творческих работ, проектов и идей с автоматической сортировкой, умным поиском и генерацией портфолио.

## ✨ Возможности

### 📤 Загрузка и классификация
- **Drag & Drop** файлов прямо в браузер
- **Автоматическая классификация** по типу файла:
  - Видео → `/Видео/{год}/{месяц}`
  - Фото → `/Фото/{год}/{месяц}`
  - Документы → `/Документы/{год}`
  - Код → `/Код/{язык}`
  - Таблицы → `/Таблицы/{год}`
  - Архивы → `/Архивы`
  - Идеи → `/Идеи`
- **Автогенерация тегов** из имени файла и содержимого
- **Превью** для изображений (уменьшенные копии)

### 🔍 Поиск и навигация
- **Полнотекстовый поиск** по названию, описанию, тегам
- **Фильтры** по типу, папке, избранному
- **Сортировка** по дате, имени, размеру
- **Два режима просмотра**: сетка и список

### 📋 Портфолио
- **Генерация HTML-страницы** с галереей работ
- **3 стиля оформления**: минимал, тёмный, яркий
- **Адаптивная вёрстка** для мобильных устройств
- **Экспорт** в HTML-файл или печать в PDF

### 🔄 Синхронизация между устройствами
- **Экспорт в JSON** — полное хранилище с файлами
- **Экспорт в ZIP** — файлы + метаданные
- **Импорт** из JSON или ZIP на другом устройстве
- **Синхронизация через облако** (Dropbox, Google Drive, iCloud)

### 🎨 Интерфейс
- **Русский язык**
- **Тёмная/светлая тема** (сохраняется автоматически)
- **Адаптивный дизайн** для мобильных устройств
- **Редактирование метаданных**: имя, описание, теги, папка

## 🚀 Использование

### Локальный запуск
```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Сборка для продакшена
npm run build
```

### Как синхронизировать между устройствами

**Сценарий 1: Экспорт → Импорт**
1. На основном компьютере: нажмите "🔄 Синхронизация" → "💾 Экспорт в JSON"
2. Сохраните файл `myvault-backup-YYYY-MM-DD.json` в облако (Dropbox/Google Drive)
3. На другом устройстве: откройте приложение, нажмите "🔄 Синхронизация" → "📄 Импорт из JSON"
4. Выберите файл из облака

**Сценарий 2: Полный бэкап с файлами**
1. Экспортируйте в ZIP (включает все файлы + метаданные)
2. Храните архив в облаке или на внешнем диске
3. При необходимости импортируйте на любом устройстве

**Сценарий 3: Автоматическая синхронизация**
1. Экспортируйте JSON в папку Dropbox/Google Drive
2. Облако автоматически синхронизирует файл между устройствами
3. На каждом устройстве импортируйте обновлённый файл

## 📦 Структура данных

Все данные хранятся в **IndexedDB** браузера:
- `files` — файлы с метаданными и бинарными данными
- `portfolios` — сохранённые портфолио
- `rules` — пользовательские правила классификации

**Ограничения IndexedDB:**
- Привязка к конкретному браузеру
- Лимит ~10% дискового пространства
- Риск потери при очистке кэша
- Нет автоматической синхронизации

**Решение:** Используйте экспорт/импорт для синхронизации между устройствами.

## 🛠️ Технологии

- **React 18** + **TypeScript** — UI
- **Vite** — сборка
- **TailwindCSS** — стили
- **Zustand** — управление состоянием
- **IndexedDB** (через `idb`) — хранение данных
- **JSZip** — работа с ZIP-архивами

## 📝 Примеры использования

### Загрузка файлов
1. Перетащите файлы в окно браузера или нажмите "＋ Загрузить"
2. Файлы автоматически классифицируются и сохраняются
3. Просмотрите папки в боковой панели

### Добавление идей
1. Нажмите "＋ Загрузить" → "💡 Или записать идею текстом"
2. Введите текст идеи
3. Сохраните — идея попадёт в папку `/Идеи`

### Создание портфолио
1. Нажмите "📋 Портфолио"
2. Выберите работы (чекбоксы)
3. Укажите название и стиль
4. Нажмите "✨ Сгенерировать портфолио"
5. Скачайте HTML или распечатайте в PDF

### Редактирование метаданных
1. Кликните на файл для открытия деталей
2. Редактируйте название, описание, теги
3. Перемещайте между папками
4. Добавляйте в избранное

## 🔒 Приватность

- Все данные хранятся **локально в браузере**
- **Нет отправки** на внешние серверы
- **Нет телеметрии** или аналитики
- Полный контроль над вашими данными

## 🐛 Известные ограничения

- **Размер хранилища** ограничен доступным местом в браузере (~10% диска)
- **Нет автоматической синхронизации** — используйте экспорт/импорт
- **Привязка к браузеру** — данные не переносятся между браузерами автоматически
- **Очистка кэша** удалит все данные — делайте регулярные бэкапы

## 💡 Рекомендации

1. **Регулярно экспортируйте** хранилище в JSON/ZIP
2. **Храните бэкапы** в облаке или на внешнем диске
3. **Используйте один браузер** для основного хранилища
4. **Синхронизируйте вручную** при работе с нескольких устройств
