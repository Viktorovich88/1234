# 🗄️ Моё Хранилище (MyVault)

**Персональное хранилище файлов** — устанавливается как обычное приложение, работает на любом устройстве, автоматически сортирует файлы по категориям.

## 📲 Установка (2 минуты)

### На компьютере:
1. Откройте сайт в Chrome/Edge/Opera
2. Нажмите значок **"Установить"** в адресной строке
3. Готово! Приложение появится на рабочем столе

### На телефоне:
1. Откройте сайт в браузере
2. Нажмите кнопку **"📱 Установить на телефон"** внизу экрана
3. Следуйте инструкции для вашей платформы
4. Готово! Иконка появится на рабочем столе

**Никакого Node.js, серверов, терминала!** Просто откройте сайт и установите как приложение.

## 🎯 Как пользоваться

### Загрузка файлов:
1. Перетащите файлы или папку в окно
2. Или нажмите **"＋ Загрузить"**
3. Выберите **"📂 Выбрать папку"** для загрузки целой папки
4. Файлы автоматически рассортируются по категориям

### Загрузка целой папки:
```
📁 Моя папка
├── 📷 фото.jpg          → /Фото/2024/01/
├── 🎬 видео.mp4         → /Видео/2024/01/
├── 💻 script.js         → /Код/JavaScript/
├── 📄 документ.pdf      → /Документы/2024/
└── 📊 таблица.xlsx      → /Таблицы/2024/
```

### Добавление идей:
1. **"＋ Загрузить"** → **"💡 Записать идею"**
2. Введите текст → сохранится в `/Идеи/`

### Создание портфолио:
1. Нажмите **"📋 Портфолио"**
2. Выберите работы, стиль, название
3. Скачайте HTML или распечатайте в PDF

### Синхронизация:
1. **"🔄 Синхронизация"** → **"💾 Экспорт"**
2. Сохраните файл в облако
3. На другом устройстве — **"📄 Импорт"**

## 📦 Где хранятся данные?

Всё хранится **в браузере** (IndexedDB):
- ✅ Быстро и приватно
- ✅ Работает офлайн
- ✅ Не занимает место на диске (кроме кэша)
- ⚠️ Привязано к конкретному браузеру
- ⚠️ Делайте бэкапы!

**Важно:** Регулярно экспортируйте хранилище в облако!

---

## 🔄 Синхронизация между устройствами

```
📱 Телефон → загрузили фото
    ↓
📤 Экспорт в JSON → сохранили в Dropbox
    ↓
💻 Компьютер → импорт из Dropbox
    ↓
📁 Все фото на компьютере!
```

**Регулярно экспортируйте** хранилище в облако — это ваш бэкап!

## 🐛 Решение проблем

**"Приложение не устанавливается"**
→ Используйте Chrome/Edge/Opera, откройте по HTTPS

**"Файлы пропали"**
→ Вы в другом браузере? Используйте импорт из бэкапа

**"Медленно работает"**
→ Слишком много файлов? Сделайте архив старых

**"Не могу загрузить папку"**
→ Используйте Chrome или Edge (Safari не поддерживает)
