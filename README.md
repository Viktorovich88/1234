# ☠ MYVAULT — Хранилище Мёртвых Файлов

## 🎨 Дизайн

### Dark Neon Skull Theme
- **Цветовая схема**: глубокий фиолетовый (#7c3aed), чёрный (#07060d), неоновый синий (#3b82f6), акценты розового (#ec4899)
- **Иконки**: уникальные SVG-черепа для каждой категории с неоновыми эффектами
- **Анимации**: плавающие черепа, пульсирующее свечение, сканирующие линии
- **Эффекты**: glassmorphism, градиенты, неоновое свечение, фоновая сетка

### Заставка
При запуске приложения показывается анимированная заставка:
- Большой череп с неоновыми глазами
- Сканирующие линии на фоне
- Плавающие черепа в фоне
- Прогресс-бар загрузки
- Статусные сообщения в стиле терминала

## 🚀 Быстрый старт

### Установка как приложение

**Компьютер:**
1. Откройте сайт в Chrome/Edge/Opera
2. Нажмите значок "Установить" в адресной строке
3. Готово!

**Телефон:**
1. Откройте сайт в браузере
2. Нажмите кнопку "📱 Установить на телефон" внизу экрана
3. Следуйте инструкции

### Использование

1. **Загрузите файлы** — перетащите или нажмите "＋ Загрузить"
2. **Загрузите папку** — нажмите "📂 Выбрать папку"
3. **Файлы автоматически рассортируются** по категориям
4. **Используйте поиск и фильтры** для навигации
5. **Создайте портфолио** — нажмите "📋 Портфолио"

## 🎯 Особенности дизайна

### Неоновые эффекты
- Светящиеся глаза у черепов
- Пульсирующее свечение при наведении
- Градиентные фоны с неоновыми акцентами
- Анимированные сканирующие линии

### Анимации
- `skullFloat` — плавающие черепа
- `neonPulse` — пульсирующее свечение
- `eyeGlow` — светящиеся глаза
- `scanline` — сканирующие линии
- `fadeIn` / `slideUp` — появление элементов

### Типографика
- Заголовки: жирные, с градиентным текстом
- Моноширинный шрифт для статусов и кода
- Uppercase для заголовков секций

## 🐛 Решение проблем

**"Заставка не пропадает"**
→ Подождите 3-5 секунд, загрузка завершится автоматически

**"Иконки не отображаются"**
→ Обновите страницу (Ctrl+F5)

**"Цвета слишком яркие"**
→ Дизайн специально сделан в неоновом стиле для уникальности
