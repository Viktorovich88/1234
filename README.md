# 🗄️ MyVault — Локальное хранилище файлов

**Персональное облако на вашем компьютере** — загружайте файлы с любого устройства, всё хранится у вас.

## 🎯 Как это работает

```
┌─────────────────┐     ┌─────────────────┐     ┌─────────────────┐
│   📱 Телефон    │     │   💻 Ноутбук    │     │   🖥️ Планшет    │
│   (браузер)     │     │   (браузер)     │     │   (браузер)     │
└────────┬────────┘     └────────┬────────┘     └────────┬────────┘
         │                       │                       │
         └───────────────────────┼───────────────────────┘
                                 │
                                 ▼
                    ┌────────────────────────┐
                    │   🏠 Ваш компьютер     │
                    │   (Node.js сервер)     │
                    │                        │
                    │   📁 myvault-storage/  │
                    │   ├── Фото/            │
                    │   ├── Видео/           │
                    │   ├── Документы/       │
                    │   └── ...              │
                    └────────────────────────┘
```

## ✨ Возможности

- 📤 **Загрузка с любого устройства** — телефон, планшет, другой ПК
- 🤖 **Автоматическая сортировка** — файлы раскладываются по папкам
- 🏷️ **Автогенерация тегов** — из имени файла и содержимого
- 🔍 **Умный поиск** — по названию, тегам, описанию
- 📋 **Генерация портфолио** — HTML-страница с вашими работами
- 🌐 **Доступ по локальной сети** — с любого устройства в WiFi
- 💾 **Всё на вашем компьютере** — полный контроль над данными

## 🚀 Быстрый старт

### Windows:
```
1. Дважды кликните install.bat
2. Дождитесь установки
3. Запустите start.bat
4. Откройте http://localhost:3001
```

### macOS / Linux:
```bash
chmod +x install.sh
./install.sh
cd server && npm start
```

### Вручную:
```bash
# 1. Установите зависимости
cd server && npm install
cd ../client && npm install

# 2. Соберите клиент
cd ../client && npm run build

# 3. Соберите и запустите сервер
cd ../server && npm run build && npm start
```

## 📱 Доступ с телефона

1. Убедитесь, что телефон в **той же WiFi сети**
2. Посмотрите IP-адрес компьютера в консоли сервера:
   ```
   📱 Доступ с телефона: http://192.168.1.100:3001
   ```
3. Откройте этот адрес в браузере телефона
4. Загружайте файлы — они сохранятся на компьютере!

## ⚙️ Настройка

### Изменить папку хранения:
```bash
# Linux / macOS
STORAGE_PATH=/mnt/data/myvault npm start

# Windows
set STORAGE_PATH=D:\MyVault
npm start
```

### Изменить порт:
```bash
PORT=8080 npm start
```

## 🔄 Автозапуск

### Windows:
Скопируйте `start.bat` в папку автозагрузки:
`Win+R` → `shell:startup`

### macOS:
Создайте LaunchAgent (см. INSTALL.md)

### Linux:
Создайте systemd service (см. INSTALL.md)

## 🛡️ Безопасность

- ✅ Все данные хранятся **локально** на вашем компьютере
- ✅ Нет отправки на внешние серверы
- ✅ Доступ только из вашей сети (по умолчанию)
- 🔒 Для доступа из интернета — настройте авторизацию!

## 📊 Технологии

**Сервер:**
- Node.js + Express — API сервер
- SQLite (better-sqlite3) — база данных
- Sharp — генерация превью
- Multer — загрузка файлов

**Клиент:**
- React 18 + TypeScript
- TailwindCSS — стили
- Zustand — управление состоянием

## 🐛 Решение проблем

**Не могу подключиться с телефона:**
- Проверьте, что устройства в одной WiFi сети
- Разрешите порт 3001 в файрволе
- Попробуйте отключить антивирус

**Сервер не запускается:**
- Убедитесь, что Node.js 18+ установлен
- Проверьте, что порт 3001 свободен
